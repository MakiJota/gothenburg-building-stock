# Gothenburg building stock 1960–2015

Interactive companion site to the preprint
**From Urban Growth to Material Accumulation: Reconstructing Building Stock Dynamics in Gothenburg, from 1960 to 2015**
([Research Square rs-11133928/v1](https://www.researchsquare.com/article/rs-11133928/v1)).

Live site: https://makijota.github.io/gothenburg-building-stock/

## What it shows

- **Map** of the building stock for every Time Model layer (1960–2015, five-year steps) plus a
  "<1960" view of the 1960 stock by construction period.
  - *Stock*: buildings standing in a year, coloured by function, structural typology or construction period.
  - *Change*: buildings added and demolished between two consecutive layers.
  - *Swipe*: previous layer vs selected layer side by side.
  - *Grid*: 100 / 250 / 500 m cells summing building count, footprint, floor area or residential materials (tonnes, 17 categories).
- **Charts**: residential material inflow/outflow per period, the 1960 → 2015 stock balance, cumulative flows.
- **Report**: methods, results and the machine-learning appendix of the preprint.

Views are shareable: the URL keeps the state, e.g. `?y=1970&view=change&layer=grid&mat=mt`.

## Data and licensing

No building geometries or building-level attributes are published here. Buildings are shown as
pre-rendered raster tiles whose pixel colours encode a class (function, typology, construction
period), which the browser recolours; the grid files contain only per-cell sums.

Source: *GIS-based Time Model of Gothenburg, 1960–2015* (Stavroulaki et al., 2025, Chalmers University
of Technology, doi:10.5878/MA55-R589). Material intensities: Gontia et al. (2018).

## Structure

```
index.html, css/, js/          static site (Leaflet, D3, d3-sankey, proj4 from CDNs)
tiles/s<year>/z/x/y.png        stock layers (class-encoded)
tiles/c<year>/z/x/y.png        change layers: new / demolished in (year-5, year]
data/grid/                     grid aggregates, data/flows.json chart data, data/tiles.json
img/                           preprint figures
```

The data files are generated by the R scripts in the research repository
(`dashboard/scripts/01_buildings.R` … `04_flows.R`).
